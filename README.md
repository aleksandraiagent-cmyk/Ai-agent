# Терминал анализа акций — сигнал «Покупать / Продавать» (приложение для компьютера)

Тот же терминал, что и в Claude (`app/index.html` — копия артефакта со всеми вкладками), но работает на вашем компьютере.
Задачи кнопок, которые в Claude выполняют запланированные задачи, здесь выполняет локальный сервер `terminal_app.py`
через Yahoo Finance (yfinance). Учебный инструмент, не инвестиционная рекомендация.

## Готовый exe (Windows)

Скачайте `TerminalApp-windows` во вкладке **Actions** репозитория (последняя успешная сборка → блок **Artifacts**),
распакуйте и запустите `TerminalApp.exe`. Окно консоли не закрывайте — это сервер терминала.

## На iPhone (через компьютер в той же Wi-Fi сети)

1. На компьютере дважды щёлкните `Запуск для iPhone.bat` (лежит рядом с `TerminalApp.exe`).
   Если Windows спросит про брандмауэр — разрешите доступ в **частных** сетях.
2. В окне появится адрес вида `http://192.168.1.5:8765/` — откройте его в Safari на iPhone.
3. «Поделиться» → «На экран «Домой»». Терминал откроется со своего значка на весь экран.

Компьютер с терминалом должен быть включён. Используйте только домашнюю Wi-Fi сеть: пароля у терминала нет.

## Запуск через Python

```
pip install -r requirements.txt
python terminal_app.py            # браузер
python terminal_app.py --window   # отдельное окно
python terminal_app.py --lan      # открыть с телефона в той же Wi-Fi сети
python terminal_app.py --refresh  # только обновить все котировки и выйти
```

## Что делают кнопки в приложении

| Кнопка терминала | Что делает приложение |
|---|---|
| ⟳ Обновить (все / один тикер) | выгружает из Yahoo 1д (5 лет), 1ч (730 дней), 5м (60 дней), 1мес, новости, премаркет/постмаркет, отчётность, оценки, справедливую цену |
| Поиск любого тикера | ищет бумагу на Yahoo и добавляет её в `extra.json` |
| Аналитики → обновить | рейтинги и целевые цены банков за 30 дней из Yahoo (пояснения, собранные раньше в Claude, сохраняются) |
| Новости Форекс → обновить | собирает Claude с веб-поиском, если задан `ANTHROPIC_API_KEY`; иначе показываются последние сохранённые |

При первом запуске в папку `terminal_data` рядом с exe копируются данные из Claude (на 10.11.2026), поэтому терминал сразу открывается с котировками.

Без Claude недоступны ИИ-резюме и «живой пересказ» (в Claude их даёт встроенный ИИ артефакта).

## Сборка exe самостоятельно

`build_exe.bat` или автоматическая сборка GitHub Actions (`.github/workflows/build-exe.yml`), которая перед сборкой
проверяет формат выгрузки на живом Yahoo (`tools/check_format.py`).
