# Терминал сигналов «Покупать / Продавать»

Учебный аналитический терминал по акциям США и криптовалютам. Сигналы рассчитываются алгоритмически и **не являются инвестиционной рекомендацией**.

## Быстрый старт

```bash
pip install -r requirements.txt
python terminal_app.py            # сервер + браузер (http://127.0.0.1:8765)
python terminal_app.py --window   # отдельное окно (pywebview)
python terminal_app.py --lan      # открыть с телефона в той же Wi-Fi сети
```

Нажмите **«⟳ Обновить»**: одно нажатие выгружает все 29 тикеров из Yahoo Finance через `yfinance` (3–6 минут), график и карточки перерисуются сами. Автообновления по расписанию нет. Пока данных нет, терминал работает на **демо-данных** (помечены «DEMO»).

Функции Claude (сбор новостей Форекс с оценкой влияния, «живой пересказ», оценка своих заголовков, «Проверить свою новость») работают, если установлен `anthropic` и задана переменная `ANTHROPIC_API_KEY`. Без ключа терминал оценивает новости по словарю ключевых слов.

### Сборка .exe (Windows)

```bat
build_exe.bat
```

Получится `dist\TerminalApp.exe`; данные хранятся в папке `terminal_data` рядом с местом запуска.

## Методика

Итоговый балл (−100…+100) = сумма оценок 9 факторов (−1…+1) × вес:

| Фактор | Вес |
|---|---|
| Облако Ишимоку 9/26/52 (сдвиг как в TradingView) | 18 |
| EMA20, SMA50, SMA200 | 14 |
| Боллинджер 20, 2σ | 10 |
| VWAP ±1σ/±2σ (внутри дня — сессионный) | 10 |
| Поток денег / Time & Sales (CMF, OBV, дельта, всплески объёма) | 12 |
| Уровни и ликвидность | 12 |
| Японские свечи по Гусеву (+ три разрыва Сакаты) | 14 |
| Новости (только заголовки про саму бумагу) | 5 |
| Психология рынка (индекс страха и жадности) | 5 |

* **ПОКУПАТЬ** — балл ≥ +22 и уверенность ≥ 55%; **ПРОДАВАТЬ** — балл ≤ −22 и уверенность ≥ 55%; иначе **ВНЕ РЫНКА (ОЖИДАНИЕ)**.
* Уверенность = 55% × сила перевеса + 45% × согласие факторов; разворотная модель Гусева против сигнала — −12.
* Риск/прибыль до ближайшего уровня < 1,3 → ожидание (правило санпо).
* Режим «Только покупки» (по умолчанию): вместо «ПРОДАВАТЬ» — «НЕ ПОКУПАТЬ (В СТОРОНЕ)».
* Шкала = 50 + балл / 2.

Все пороги, периоды индикаторов и веса меняются в «⚙ Параметры».

## Состав

* `terminal_app.py` — сервер на Python (стандартная библиотека + yfinance), API данных, фоновые загрузки, Claude.
* `web/` — терминал (чистый JS, без внешних библиотек):
  * `js/indicators.js` — индикаторы; `js/candles.js` — модели Гусева и точки ПОКУПКА/ВЫХОД/ПРОДАЖА;
  * `js/analysis.js` — 9 факторов, сигнал, план сделки, справедливая стоимость, бэктест, подбор весов;
  * `js/chart.js` — график (12 слоёв, масштаб, перетаскивание, перекрестие);
  * `js/app.js` — вкладка «Терминал», избранное, тема, язык, путеводитель, озвучка;
  * `js/tabs.js` — «Новости Форекс», «Аналитики», «Инвестпакет», «Календарь биржи», «Усреднение».

Свои данные: кнопка **CSV** (дата, открытие, максимум, минимум, закрытие, объём).

Даты макростатистики США во встроенном календаре ориентировочные (помечены «≈»); заседания ФРС на 2027 год — предварительные.
